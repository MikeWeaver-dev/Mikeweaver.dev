**Background**

This website is the landing page for my personal software portfolio. It includes several major projects that showcase my coding abilities. The projects offer AI integration, complex CRUD database manipulation, several API calls working in tandem, data analytics, and more. In general, I tried to make a diverse portfolio using Javascript, Python, R, React, React Native, TailWind CSS, Nativewind, and more languages.

The website itself isn't an exceptionally interesting software development, though I did try to add some spicy UI and cool stuff! I hope you visit the site (mikeweaver.dev) and maybe take a peak under the hood at my source code!

**Installation**
- Install node.js, Vite, React, Tailwind
- On PC, run "npm create vite@latest"
- Select Javascript & React
- Leave node_module untouched. Update the other folders with my code here on Github
